# ⌚ ARCWATCH — Premium Smartwatch Landing Page

A modern, responsive, and production-ready smartwatch e-commerce landing page built with **HTML5**, **CSS3**, and **Vanilla JavaScript**. ARCWATCH delivers a premium user experience with glassmorphism effects, dynamic product rendering, shopping cart functionality, wishlist management, dark/light themes, and smooth animations.

---

https://smart-watch-landing-page-gules.vercel.app/
